# WatchMyPhone

WatchMyPhone is a privacy-focused Android security app that detects unauthorized access attempts. It captures intruder photos, logs unlock attempts and screen activity, tracks which apps were opened by the intruder, and offers a clean dashboard to review incidents. Built with modern Android architecture (MVVM, Hilt, Room, Flow).

## Summary

WatchMyPhone helps you protect your phone from unauthorized access. Whenever someone tries to unlock or use your device without permission, the app silently records important evidence such as the intruder’s photo, activity events, and app usage. All data is stored locally and presented in a simple dashboard so you can easily review what happened and when.

Key highlights:

* Detects suspicious phone activity
* Captures intruder photos using the front camera
* Logs events like unlock attempts and screen on/off
* Tracks which apps were opened by the intruder
* Offline-first with local data storage
* Built with modern Android components (MVVM, Hilt, Room, Flow)

---

## Usage

1. Install the app and grant required permissions (Camera, Notifications, Foreground Service).
2. Turn ON monitoring using the power button on the home screen.
3. Leave your phone locked as usual.
4. If someone tries to unlock or access your phone, WatchMyPhone will:

   * Capture a photo (if available)
   * Log the event time and type
   * Record which apps were opened
5. Open the app anytime to view the intruder list and tap an item to see details.

This makes it easy to understand exactly what happened when your phone was used without your knowledge.
